# JANJI-ROCQ
This repository contains the official reference implementation supporting the results of the paper [Hard-KLAIM for Hardening Agentic Workflows: A Locality-Aware Type-and-Effect System for Trace Safety (Aldinuccci, Bracciali, Colonnelli, Medic, Mulone, Roversi, Santimaria)]. The code is released under the MIT/Apache‑2.0 license to maximize reproducibility and scientific reuse.
