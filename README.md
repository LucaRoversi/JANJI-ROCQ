# JANJI-ROCQ
This repository contains the official reference implementation in ROCQ that supports the correctness of the results in the paper [Hard-KLAIM for Hardening Agentic Workflows: A Locality-Aware Type-and-Effect System for Trace Safety (Aldinucci, Bracciali, Colonnelli, Medic, Mulone, Roversi, Santimaria)]. The code is released under the MIT/Apache‑2.0 license to maximize reproducibility and scientific reuse.
